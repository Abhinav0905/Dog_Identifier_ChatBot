QUICK START (Python 3.10+)

git clone --branch review/single-agent-2026-10-30 https://github.com/Abhinav0905/Dog_Identifier_ChatBot.git
cd Dog_Identifier_ChatBot
python3 -m venv .venv
source .venv/bin/activate
python -m pip install openai==2.30.0

Supply OPENAI_API_KEY through your normal local environment or secret manager.
The standalone CLI reads environment variables; it does not load .env itself.
Model defaults are gpt-5.6-terra for both main and vision calls. If your account
needs a different model, use --model and --vision-model and record that change;
results on a different model are not a repeat of the saved baseline.

One fresh question:
python -m simple_agent --question 'Where can an injured community dog get treatment in Mysuru?' --output .codex-build/team-question-01

One photo:
python -m simple_agent --question 'What can you see in this photo?' --image example_images/dog_1.png --output .codex-build/team-photo-01

Original 50-question set, with ordered conversation history:
python -m simple_agent --suite core50 --output .codex-build/team-core50-01

Original 50 plus eight guardrail/photo checks:
python -m simple_agent --suite all58 --output .codex-build/team-all58-01

Use a NEW output directory for each run. Calls use the configured API account.
Read <case>.json for the answer and citations, and traces/<case>.jsonl for model
calls, search sources, tool results and errors. The runner marks answers
UNREVIEWED: an HTTP/API completion is not an accuracy pass.

For custom ordered follow-ups, use the SingleAgent API with the SAME history
list between turns; use a new empty list for a genuinely new conversation:

from pathlib import Path
from openai import OpenAI
from simple_agent.agent import SingleAgent

agent = SingleAgent(OpenAI(max_retries=0))
history = []
result = agent.turn("I need a vet in Hamirpur, Himachal Pradesh.", history,
                    trace_path=Path(".codex-build/team-multiturn/turn1.jsonl"))
print(result["answer"])
result = agent.turn("A completely different case: an injured dog in Una. Where can I take it?", history,
                    trace_path=Path(".codex-build/team-multiturn/turn2.jsonl"))
print(result["answer"])

The second turn should clarify the state; the saved final run did not. Other
custom turns can pass image_path=Path("photo.png") for a supplied attachment.
