RCA runtime contracts release (v2.8)

Base: deployed source 440951f, prompts srini-v2.4-2026-10-25.

Changes:
- Separate explicitly named institution lookups from stored animal-case geography.
- Share address-only/phone-only contracts across routing, search and fallback.
- Normalize natural city/state qualifiers; reject explicitly conflicting source states.
- Retain same-name geocoder candidates across states and request qualification.
- Compose requested handling/care with verified provider output. Extend animal safety
  coverage to cats/kittens. Keep general safety available at the India-only boundary.
- Route out-of-scope writing tasks to an application-owned animal-welfare redirect.
- Answer pickup/admission availability directly with a call-to-confirm step.
- Use current-message or explicitly requested language before browser locale/history.
- Record correlated stage diagnostics without credentials; expose functional outcome
  aggregates separately from model readiness.
- Preserve separately published adjacent phone numbers in directory rows.
- Keep explicitly labelled regional directory leads as incomplete referrals when
  a facility city cannot be proved; never present them as confirmed local treatment.
- Bind a neighbourhood to its city only through fetched address evidence and label
  that geographic source separately from facility contact evidence.
- Refuse invented-contact requests early and retain their chat evidence.
- Bound evidence fetching with a shared four-worker pool and bounded submission queue.

All model prompt changes remain in prompts/runtime-v2 text files. The original Deb
reference text and historical prompt source blocks are preserved. Clinical numbers,
addresses and services still require entity-bound source evidence. Published services
do not establish current admission or dispatch.
